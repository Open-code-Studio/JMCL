# 2026-06-19

## DMG 打包修复
- **问题**: `build-jpackage.sh` 多次失败
  1. `jpackage NoSuchElementException` — 旧 JDK (Microsoft OpenJDK 21) 缺少 `jmods/`
  2. `jpackage SIGBUS` — Adoptium JDK 21.0.11 在 macOS 26/Apple Silicon 上 JVM 崩溃
  3. `posix_spawn` 失败 — 旧 JDK 的 jpackage 调用 codesign 需要 FORK 机制
- **解决方案**:
  - 从清华镜像下载 Adoptium JDK 21.0.11 → `/Users/cangcang/Documents/jdk21-full`
  - 用旧 JDK (Microsoft) 运行 jpackage（不崩溃），从新 JDK 的 jmods 用 jlink 创建 runtime image
  - jpackage 阶段恢复 `_JAVA_OPTIONS=-Djdk.lang.Process.launchMechanism=FORK`（旧 JDK 需要）
- **修改**: `build-jpackage.sh`
  - JDK 检测优先旧 jdk21，新增 `resolve_jdk()` 兼容 macOS .app bundle 结构
  - 新增 Step 5a: jlink 创建 runtime image
  - 细化 `_JAVA_OPTIONS` 控制：jlink 时 unset，jpackage 时 set
  - 每次 retry 前清理残留 .app 目录
- **结果**: `dist/JMCL-2026.1.0.dmg` (76MB) 构建成功
