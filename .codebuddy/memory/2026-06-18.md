# 2026-06-18

## InstanceManagerWindow 悬浮窗跟随修复
- 原实现仅支持 macOS 且 `osascript` 脚本不够健壮
- 重写为跨平台实现：
  - **macOS**: 改进 `osascript`，遍历所有窗口查找 `AXMain` 主窗口，失败时 fallback 到第一个窗口
  - **Windows**: 使用 PowerShell 内嵌 C# P/Invoke (`EnumWindows` + `GetWindowRect`) 按 PID 查找窗口
  - **Linux/FreeBSD**: 使用 `xdotool search --pid` + `getwindowgeometry --shell`
- 提取 `runScript()` 通用辅助方法

## NBT 编辑器完善
- **NBTFileType**: 新增 `write()` 方法和 `writeCompressed()` 辅助方法，支持 COMPRESSED (GZIP) / ANVIL / REGION 三种格式的写回
- **NBTEditorPage**: 
  - `save()` 从 TODO 实现为完整功能，调用 `type.write(file, rootElement)`
  - 修复布局 bug：actions 栏（save/cancel 按钮）原未加入 UI（仅创建未添加），现用 VBox 包裹
  - 保存 `rootElement` 和 `treeView` 引用
- **NBTTreeCell**: 
  - 双击 ValueTag 节点可内联编辑（TextField）
  - 支持 Enter 提交、Escape 取消、焦点丢失自动提交
  - 编辑后将新值解析为对应 Tag 类型，通过 `CompoundTag.addTag()` 或 `ListTag` 快照替换更新父节点
  - 支持 Byte/Short/Int/Long(含十六进制)/Float/Double/String 的解析
